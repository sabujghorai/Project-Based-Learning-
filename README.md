# 🚀 Project-Based Learning

Welcome to my **Project-Based Learning** repository! 👋

This repository contains the projects I build while learning and improving my skills in **Python, Data Structures & Algorithms, Data Analysis, Linux, DevOps, Cloud, and MLOps**.

Instead of only learning theory, I use this repository to **learn by building real projects**.

---

## 🎯 Goal

The main goal of this repository is to:

- 🧠 Strengthen programming fundamentals
- 🛠️ Learn by building practical projects
- 📚 Apply concepts learned from courses and documentation
- 🧩 Improve problem-solving skills
- ☁️ Explore DevOps, Cloud & MLOps
- 📈 Track my progress over time
- 💻 Build projects that can be added to my portfolio
